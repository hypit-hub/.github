[Hypit](https://github.com/hypit-ai/hypit) 是一个开源视频引擎：在你自己的机器上用 headless
Chromium 渲染，通过 CLI 和你自己的 API key 驱动。强大，但大多数创作者够不着。**Hypit Hub**
是社区围绕它构建的东西：把已经跑通的结构做成可直接 fork 的模板，并把枯燥的中间环节自动化。

## 我们在做什么

| | 内容 | 位置 | 状态 |
|---|---|---|---|
| 🎬 **模板** | SVML 预设，直接阅读完整脚本、分镜、可改写提示词和交付检查表。换掉产品，保留那些已经带来播放量的结构。 | [hypit.si/zh/templates](https://hypit.si/zh/templates) | 持续补充 |
| 🔁 **工作流** | n8n 流水线：盯住一个垂类、用引擎批量复刻、排队自动发布。 | — | 🚧 规划中 |
| ☁️ **云端** | 同一个引擎装进浏览器：选模板、填产品、出视频。不用终端，不碰 Node。 | — | 🚧 开发中 |
| 🌐 **网站** | 落地页、模板库、候补名单：[hypit.si](https://hypit.si/zh)。 | 本组织 | ✅ 已上线 |

## 参与进来

- **加入候补名单**：[hypit.si](https://hypit.si/zh)。beta 上线时只发一封邮件，绝不多发；上线名额按候补顺序。
- **Watch 仓库**：所有产出随做随发，全程公开。
- **公开构建**：进展、踩过的坑、渲染产出，都会实时发布。
